# SpendGrid Web

Official landing page and legal documentation for **SpendGrid: Track Expenses**, the intuitive and privacy-focused way to manage personal finances on iOS and Android.

## 🚀 Overview

This repository hosts the static web pages for SpendGrid. It includes the main landing page, privacy policy, and terms of use, all designed with a clean, modern aesthetic.

## ✨ Key Features

- **Privacy First**: Built with a local-first philosophy — your financial data is never sent to our servers.
- **Intuitive Tracking**: Log transactions in seconds with smart categorization.
- **Visual Insights**: Beautiful, interactive charts and a calendar view to help you understand spending habits.
- **Budget Tracking**: Set monthly budgets per category and track progress in real time.
- **Recurring Transactions**: Automate bills, subscriptions, and income with scheduled reminders.
- **Multi-Currency**: Search and switch between currencies from around the world.
- **Data Portability**: Export your records to CSV anytime for deeper analysis.
- **Local & Secure**: Powered by a local on-device database — no account or server required.

## 📂 Repository Structure

- `index.html`: The main landing page providing an overview of the app and quick links to legal docs.
- `privacy.html`: Official Privacy Policy detailing our commitment to data security and local storage.
- `terms.html`: Terms of Use governing the app's usage and user responsibilities.
- `legal-styles.css`: The central design system and styling for all documentation pages.

## 🛠️ Tech Stack

- **HTML5**: Semantic structure for accessibility and SEO.
- **CSS3**: Custom design system with a focus on typography, spacing, and responsive layouts.
- **No Dependencies**: Lightweight and fast-loading with zero external libraries.
